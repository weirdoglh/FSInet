## Simulation for cortico-striatal circuit

### Code

Simulation is run with nest simulator [https://www.nest-simulator.org/].

Codes for MSN network simulation are in runcor.py. Scale parameter can be adjusted to change the level of neuronal heterogeneity.

Codes for GPe neuron simulation are in rungpe.py.

Corresponding data processing and figure generation are given in figs.ipynb.

The distribution of F-I curves and synaptic strengths can be visualized in nrn.ipynb.

### Processed data

Processed data are in exp folder for homoegeneous network simulation (rec_0_str) and heterogeneous network simulation (rec_30_str and rec_60_str).
